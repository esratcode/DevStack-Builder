# Dev Stack Builder

A responsive React-based website that helps developers explore modern technologies and build their own development stack.

## Technologies Used

- React
- JavaScript
- Vite
- CSS
- React Toastify
- JSON

## Features

1. **Explore Technologies**
   Browse popular frontend, backend, database, language, styling, DevOps, and developer tools.

2. **Build Your Stack**
   Add technologies to your personal stack, prevent duplicate selections, remove individual items, or remove all technologies.

3. **Responsive Design**
   Fully responsive layout with desktop, tablet, and mobile navigation.

## React Questions & Answers

### 1. What is React?

React is a JavaScript library used to build user interfaces, especially for web applications.

### 2. What is JSX?

JSX is a syntax extension for JavaScript that allows us to write HTML-like code inside JavaScript.

### 3. What is a component?

A component is a reusable part of a React application that contains its own structure and logic.

### 4. What is state in React?

State is data managed inside a component that can change over time and cause the UI to update.

### 5. What is a hook?

A hook is a special React function that allows functional components to use features such as state and lifecycle behavior.

### 6. What is useState?

`useState` is a React Hook used to create and manage state inside a functional component.

### 7. What is useEffect?

`useEffect` is a React Hook used to perform side effects such as fetching data, setting timers, or interacting with external systems.
